# Cómo contribuir

¡Gracias por el interés! 

1. Haga un fork y cree una rama: `git checkout -b mi-mejora`.
2. Siga la instalación del [README](README.md) con una base de datos de prueba.
3. Mantenga la lógica de negocio en `app/*.py` y la interfaz en `app/ui/`.
4. Verifique que el código compile: `python -m compileall app`.
5. Abra un Pull Request describiendo qué cambia y por qué.

Para errores, abra un issue con pasos para reproducir, versión de Python y MySQL.
Nunca incluya credenciales ni datos reales de clientes.
